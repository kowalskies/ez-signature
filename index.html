Install instructions

I use classic Outlook on Windows
  1. Click Copy signature for Outlook above.
  2. In Outlook: File › Options › Mail › Signatures.
  3. New, name it, then paste into the editing box.
  4. Set it as the default for new messages and for replies, then OK.

If roaming signatures is on for your mailbox, it appears in Outlook on the web after you restart Outlook.

Pasting copies the images into Outlook's own local store. If the logo or banner is updated later, your installed signature keeps the old one until you paste a fresh copy.
I use new Outlook on Windows
  1. Click Copy signature for Outlook.
  2. Settings (gear) › Accounts › Signatures.
  3. Paste, name it, assign it to new messages and replies, then Save.
New Outlook does not inherit signatures from classic Outlook — the two store them separately. If you use both, install in both.
I use Outlook in a browser or the PWA
  1. Click Copy signature for Outlook.
  2. Settings › Mail › Compose and reply.
  3. Paste into the signature box, tick both default checkboxes, then Save.
Outlook on the web rejects signatures over roughly 8,000 characters with “the text you typed is too long”. Watch the size line under the preview. If you hit it, clear anything already in the box before pasting.
I use Outlook on Mac
  1. Click Copy signature for Outlook.
  2. Outlook › Settings › Signatures, then +.
  3. Paste, name it, close the window, then set it as default per account.

Bahnschrift is a Windows font, so on Mac the signature renders in Arial. That is expected.

I use Outlook on my phone
  1. Click Copy the mobile version.
  2. In the Outlook app: profile icon › Settings › Signature.
  3. Clear what is there and paste.
Logos and banners are not possible on mobile — the app has a plain-text field only. The mobile signature also does not sync from desktop, so each phone needs this done once.
